## Hallazgos de contenido y metadatos

- Los títulos de portada priorizan “Desarrollo de software a la medida” / “Custom software development”; los índices del blog tienen títulos descriptivos y diferentes por idioma.
- Cada página conserva un H1, descripción y contenido propio; cada artículo enlaza su traducción equivalente. Las rutas y anclas internas resuelven.
- Open Graph tiene URL canónica, título, descripción e idioma alternativo; Twitter incluye título y descripción. `BlogPosting` añade un publisher real: Cuy Coders.
- No se fabrican reseñas, nombres de clientes, precios, direcciones ni métricas de proyectos. No se añade schema de negocio local sin datos de ubicación.
- HTML hreflang es la única fuente de alternancias; el sitemap lista URLs. [Google considera equivalentes HTML, HTTP y XML para hreflang](https://developers.google.com/search/docs/specialty/international/localized-versions), por lo que no se duplica la configuración.

## Plan pendiente de publicación

1. Publicar en `cuycoders.com` con HTTPS; configurar en el hosting la redirección HTTP 301 de `/` a `/es/`, normalización del host y trailing slash. La raíz actual conserva el redirect HTML de Astro estático.
2. Configurar compresión Brotli/gzip y caché larga para `/_astro/*` con hash. HTTPS, certificados, redirecciones y cabeceras se verifican contra el hosting real; localhost no los demuestra.
3. Mantener el formulario como demostración hasta conectar el contacto autorizado, como pidió el propietario. Incorporar datos reales de contacto y casos documentados cuando se suministren.
4. Verificar el dominio en Search Console, enviar `https://cuycoders.com/sitemap-index.xml` y revisar indexación y Core Web Vitals de campo cuando haya tráfico. Validar los artículos con Rich Results Test tras publicar.
5. Añadir una imagen de marca real para Open Graph y portadas de artículos cuando exista. Es una mejora de presentación, no se declara un asset que aún no se ha proporcionado.

Lighthouse conserva una sugerencia menor sobre CSS bloqueante (unos 120–140 ms estimados). Con la carga actual y puntuaciones de 100 no se difiere la hoja principal: hacerlo puede producir una vista sin estilos. Revisar otra vez al incorporar imágenes, servicios externos o nuevas fuentes.

## Repetir las verificaciones

```sh
npm run check
npm run test:seo
npm run build
npm run verify:build
npm run preview -- --port 4322
npx lighthouse http://localhost:4322/es/ --output=json --output-path=lighthouse.json --chrome-flags='--headless --no-sandbox'
```

El verificador detecta títulos repetidos, saltos de encabezados, enlaces rotos, clusters hreflang no recíprocos y excesos sobre presupuestos de HTML/CSS comprimidos y subconjuntos tipográficos. Prettier se mantiene como formateador según la preferencia final del propietario.

Referencias: [títulos en Google Search](https://developers.google.com/search/docs/appearance/title-link), [carga de fuentes](https://web.dev/articles/optimize-webfont-loading), [alternancias de idiomas](https://developers.google.com/search/docs/specialty/international/localized-versions).
